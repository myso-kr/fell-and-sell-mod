# Korean translation glossary

The patch covers 1,243 extracted entries: 1,128 game entries and 115 UI entries. Items, furniture, crafting, effects, tutorials, conversations and quests are included. In-game text display review was confirmed by the project owner on 2026-10-09.

English supplies the meaning and Japanese helps clarify context. Proper names in credits and punctuation-only entries may remain unchanged. New game text outside the covered tables can appear in the selected base language.

| English term | Korean | Meaning in the game |
|---|---|---|
| Comfort | 쾌적도 | Shop furniture stat |
| Prestige | 명성 | Shop furniture stat |
| Tip | 팁 | Customer gratuity |
| Stamina | 기력 | Combat resource |
| Recipe | 제작법 | Crafting unlock |
| Chest | 보관함 / 보물 상자 | Storage furniture / dungeon reward |
| Table | 진열대 | Sale display furniture |
| Prayer / Boon | 기도 / 은총 | Acquired effect / selection prompt |
| Affix | 특성 | Extra enemy modifier |
| Common / Uncommon / Rare / Epic / Legendary | 일반 / 고급 / 희귀 / 영웅 / 전설 | Item rarity |

## Report a translation problem

Include the screen or item name, the displayed Korean text and what it should mean. A screenshot helps with clipped labels and context. Submit feedback through [Issues](https://github.com/myso-kr/fell-and-sell-mod/issues).
