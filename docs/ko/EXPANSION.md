## 조작 {#controls}

| 조작 | 동작 |
|---|---|
| F8 | 한국어 설정창 열기·닫기 |
| F9 | 기존 지도의 미탐색 영역 표시 켜기·끄기 |
| M | 게임의 지도 열기 |
| M 지도 좌클릭 | 경로 안내가 켜진 상태에서 목적지 선택 |
| M 지도 우클릭 | 계단 안내로 돌아가기·자동 이동 정지 |
| F10 | 완전 경로의 자동 이동 시작·정지 |
| Esc | 자동 이동 정지·설정창 닫기 |

탐험 기능은 모두 기본 꺼짐입니다. F8에서 자동줍기·지도 공개·적 표시·경로 안내를 각각 켜세요. 지도나 게임을 조작하려면 설정창을 닫으세요. 설정은 다음 실행에도 유지됩니다.

## 요정의 빛 따라가기 {#guidance}

경로 안내를 켜면 다음 층 계단이 기본 목적지입니다. 빛이 플레이어 앞의 경로를 따라 이동하며 짧은 잔광을 남깁니다. 멀어지거나 지형에 가려지면 서서히 투명해집니다. 완전 경로의 빛은 금색, 부분 경로는 호박색입니다. M 지도에서는 녹색이 완전 경로, 주황색이 부분 경로입니다.

M 지도에서 좌클릭하면 다른 목적지를 고를 수 있습니다. 가까운 상자·출구·보스 표식이 목적지가 될 수 있습니다. **우클릭하면 계단 안내로 돌아갑니다.** 층이 바뀌면 선택한 목적지는 해제되고 새 지도와 해당 층의 계단 안내로 갱신됩니다.

부분 경로나 도달할 수 없는 경로에서는 자동 이동을 시작할 수 없습니다. 안내가 이상하면 [경로 문제 해결]({{ '/ko/help/#map' | relative_url }})을 확인하세요.

## 자동 이동 {#movement}

매번 F10이나 설정창의 시작 버튼으로 직접 이동을 시작하세요. 시작하면 지도는 닫힙니다. 수동 이동·전투·피격·메뉴·사망·포커스 상실 시 중단하며, 2.5초 동안 진행하지 못해도 멈춥니다.

닫힌 문은 직접 열어야 합니다. 자동 전투나 문 열기는 지원하지 않습니다. 자동 이동은 추가 확인 중인 기능이므로 직접 조작할 수 있는 상태에서 사용하세요.

## 주변 자동줍기와 지도 표시 {#pickup}

자동줍기는 정상 수집 가능한 주변 전리품을 대상으로 합니다. 기본 반경은 3m이며 1–4m로 설정할 수 있습니다. 게임의 무게 제한·필터·줍기 유예를 따르며 멀리 있는 아이템까지 이동하지 않습니다.

지도 공개는 기존 M 지도와 미니맵을 사용합니다. 적 표시는 현재 로드된 적만 보여줍니다. 저장된 탐색 기록과 게임의 도전과제 동작을 유지합니다. 지도는 생성된 던전에서 사용할 수 있으며 마을이나 첫 화면에는 표시되지 않습니다.
