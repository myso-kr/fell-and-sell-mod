## Korean text, from the shop to the dungeon

{{ site.data.patch.translated_entries }} entries cover menus, items, furniture, crafting, effects, tutorials, conversations and quests. English provides the meaning; Japanese helps clarify context. Korean text appears automatically after installation.

## More comfortable exploration

Turn on the tools you want with <kbd>F8</kbd>: collect nearby loot, extend the existing <kbd>M</kbd> map and follow a moving light to the next floor. Choose another destination on the map or right-click to return to the stairs.

## Start in three steps

1. [Download the packaged preview]({{ '/downloads/' | relative_url }}), rather than the source archive.
2. [Install MelonLoader and the complete patch]({{ '/installation/' | relative_url }}).
3. Start through Steam, then open <kbd>F8</kbd> to enable optional features.

The checked target is game {{ site.data.patch.game_version }} (Steam build {{ site.data.patch.steam_build }}), MelonLoader {{ site.data.patch.loader_version }} x64 and {{ site.data.patch.platform }}. Other combinations are unverified. [Get help]({{ '/help/' | relative_url }}) if something does not work.
