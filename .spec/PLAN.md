# Fell & Sell 모드 확장 구현 계획

2026-10-09 · v0.4.0 구현 프리뷰 · 게임 기능 검증 대기

목표: 기존 자동줍기·던전 지도·NavMesh를 확장해 주변 전리품 수집, 경로 표시와
자동 이동, 미탐색 지도·전리품·적 표시를 제공한다. 사용자는 **경로+자동 이동**,
**주변 획득 가능 전리품만 수집**, **도전과제 유지**를 선택했다.

형제 모드의 코드 및 Fell & Sell 1.7.1 / Steam 빌드 25480096의 IL2CPP 인터롭
메타데이터를 확인했고 확장 코드를 구현했다. 런타임 동작은 미검증이다.
설계·근거는 [초기 설계](EXPANSION.md), 실제 구조는 [ARCHITECTURE](ARCHITECTURE.md),
구현과 검증을 구분한 상태는 [STATUS](STATUS.md)에 정리했다.

## 구현 순서와 완료 기준

- [ ] 1. 읽기 전용 런타임 진단: 자동줍기·지도·NavMesh·입력 인스턴스와 생성 완료 시점 확인 → 기능별 진단 결과와 현재 층 식별자를 기록한다.
- [x] 2. 기능 설정·한국어 패널·상태 관리: 기본 메뉴, F8 한글·버튼, 종료 후 이동/마우스 복원을 소유자가 확인했다. 기능 오류는 분리해 보고한다.
- [ ] 3. 주변 자동줍기 확장: `PlayerAutoPickup`의 정상 수집 경로·반경·필터 사용 → 벽 너머/놓인 가구/중복 줍기 없이 무게·사망·UI 상태를 존중한다.
- [ ] 4. 현재 층 맵 공개와 마커: 기존 지도에 방·계단·출구·보스·상자·적 표시 → 토글 해제와 재접속에서 원래 탐색 상태가 보존된다.
- [ ] 5. 경로 표시: 플레이어용 NavMesh 경로를 지도와 월드에 렌더링 → 벽·닫힌 문·다른 층·부분 경로를 구분하고 도달 불가를 정확히 표시한다.
- [ ] 6. 자동 이동: 검증된 경로를 기존 이동 컨트롤러로 추종 → 직접 이동 입력, 정지 키, 메뉴, 사망, 층 변경, 전투 시 제어를 반환한다.
- [ ] 7. 목표와 조합: 출구·상자·사용자 핀 선택, 이동 중 주변 자동줍기 → 원격 전리품을 쫓지 않고 선택한 이동 목표를 유지한다.
- [ ] 8. 검증·배포: 순수 로직 테스트, 런타임 앵커 검사, 저장/복원/프레임 예산/입력 회귀 검증 → Actions ZIP과 문서에 실제 검증한 기능만 표시한다.

## 배포 단위

**v0.4.0 프리뷰:** 위 기능의 코드를 구현하고 빌드·순수 테스트를 수행했다.
체크박스는 인게임 완료 기준까지 포함하므로 실행 검증 전에는 닫지 않는다.
배포 태그나 공개 릴리스를 생성하지 않았다.

새 기능은 기본 꺼짐, 자동 이동은 매번 사용자가 시작하며 도전과제 처리는 그대로 유지한다.
자동 전투·상점 운영·자동 판매·순간이동·미생성 층 탐색은 후속 범위로 분리한다.

## 경로 진단과 기본 목적지 보완

- 시작점/목적지 NavMesh 조회·높이 차이·경로 상태를 구분해 진단 로그를 기록한다. 플레이어 시작점과 추종 도착 판정은 CharacterController 발밑 좌표를 사용한다.
- 활성 NextFloorTrigger를 기본 안내 목표로 선택하고 사용자 핀을 우선한다. 자동 이동은 직접 시작한다.
- M 지도 우클릭은 목표/경로/이동을 취소한다. 취소 후 기본 목표 자동 복구는 층 변경 또는 기능 재활성화 때만 허용한다.
- 빌드/26개 테스트/메타데이터 검사 후 설치하고 실제 던전 경로 결과를 확인한다.
