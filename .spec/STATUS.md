# 구현·검증 상태

2026-10-09 · v0.4.0 확장 프리뷰

| 범위 | 구현 | 검증 |
|---|---|---|
| 기존 한글 패치 | 전체 1243개·TMP fallback 유지 | v0.3.0 텍스트 표시 검수 소유자 확인 |
| 설정·한국어 패널 | F8, 전용 TMP Canvas, 영속 설정 | 소유자 한글·버튼·종료 후 이동/마우스 정상 확인 |
| 주변 자동줍기 | 반경 임시 변경·정상 수집 루프·가시선 검사 | 메타데이터 앵커 확인; 게임 확인 대기 |
| 지도·마커 | 읽기 전용 레이아웃·상자·출구·보스·적 | 메타데이터 앵커 확인; 게임 확인 대기 |
| 경로 표시 | NavMesh Walkable·높이 검증·부분 경로 구분 | 앵커 확인; 게임 확인 대기 |
| 자동 이동 | 정상 이동 입력 주입·복원·중단·막힘 감지 | 순수 로직·멤버/컬렉션 검사 19개 통과; 게임 확인 대기 |
| 도전과제 | 업적/통계 경로 변경 없음 | 게임의 기존 처리 유지 |

소유자 종료 확인 후 프리뷰를 설치하고 반복 재실행했다. 초기 메뉴 회귀를
싱글턴 backing-field 조회로 수정했고 소유자가 기본 메뉴 정상화를 확인했다.
F8 UI는 Noto TMP로 전환해 98글자 누락 0개와 소유자 화면 확인을 기록했다.
실행 로그의 기존 번역은 1243항목·699글자 누락 0개·한국어 TMP 26개다.
게임의 지속 입력 차단 플래그를 쓰는 방식에서 패널이 열린 동안의 행동 판정으로 전환했고,
소유자가 설정창 종료 후 이동·마우스 복원을 확인했다. 도움 기능의 실제 던전·수집·이동 검증은 남아 있다.
경로 자동 재시도·미생성 층·자동 전투·원격 수집은 구현 범위 밖이다.

- 기존 M 지도/미니맵 레이어 통합: 별도 지도 창 제거, 복사 텍스처와 마커/경로 표시, 클릭 목적지 선택. 소유자가 지도 표시 정상을 확인했다. 목적지 클릭은 미확인: 현재 설정은 MapOverlay=true, RouteGuide=false이고 클릭 처리는 경로 안내가 켜져야 실행된다. 활성화 후 재확인 대기.

- F8 하단 토글 회귀 조사: 소유자가 경로 안내/적 표시 토글 실패를 보고했고 설정 파일도 두 값 false였다. 글자는 TMP 화면 좌표, 버튼 입력은 IMGUI로 분리되어 있어 클릭 경계를 통합했다. `panel/Pointer.cs`는 OnUpdate에서 누름/해제를 한 번 처리하며 Widget의 동일 Hit 배열로 표시와 입력을 구성한다. GUI.matrix는 표시 중 identity로 고정 후 복원한다. 각 변경값을 settings 로그에 기록한다. 빌드와 23개 테스트 통과; 설치 후 화면 확인 대기.

- 소유자가 수정 F8의 적 표시/경로 안내 켜짐을 확인했으며 settings 로그에도 True가 기록됐다. 경로 계산은 도달 불가로 보고되어 조사 중이다. 발밑 시작점·진단 분리·NextFloorTrigger 기본 목표·우클릭 취소를 구현했고 빌드/26개 테스트 통과; 던전 검증은 대기.
