# Third-party components

- MelonLoader 0.7.3: Apache-2.0, https://github.com/LavaGang/MelonLoader.
  Referenced through NuGet for compilation and installed separately by users.
  Not bundled in mod packages.
- Game binaries and generated IL2CPP interop assemblies: local inspection only;
  not committed or redistributed.
- Noto Sans CJK KR Regular: SIL Open Font License 1.1,
  https://github.com/notofonts/noto-cjk. Distributed unchanged with
  `locale/fonts/OFL-Noto.txt`; the archive includes the font and license.
- HarmonyX 2.10.2: MIT, https://github.com/BepInEx/HarmonyX.
  Compilation reference only; the installed loader provides the runtime library.
- UnityPy 1.25.4: MIT, https://github.com/K0lb3/UnityPy.
  Local extraction tool dependency; not included in mod archives.
